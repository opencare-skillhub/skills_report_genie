## 🎯 维护指南

### 添加新版本记录
1. 创建文件: `records/development/VERSION_X_Y_CHANGELOG.md`
2. 按格式规范编写
3. 包含所有修改说明
4. 验证代码通过测试

### 添加新修复记录
1. 创建文件: `records/fixes/[问题名].md`
2. 按格式规范编写
3. 包含修复前后对比

4. 链接相关文档
